# WreckFinder React Native App.

This application allows users to research wrecks by searching for them, and viewing them on a map or chart - on their mobile device phone.

<b>Tech Stack</b>
React Native.  Uses the Wreckypedia site as a JSON API.

<b>Plans</b>
I'm working on sending this to the app store.
